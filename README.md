# 我们先说清楚 72小时未读

面向大学生和青年群体的 HIV 暴露后预防互动叙事游戏。

玩家扮演校园青年健康互助账号的学生管理员，陪伴匿名求助者 Q 处理一次无法自行判断的潜在暴露。知识不以考试题出现，而是通过整理信息、辨别误区、寻找专业评估、完成用药记录和制定预防方案逐步进入剧情。

游戏包含六个连续章节：

- 凌晨的消息：用信息拼图区分必要信息与无关隐私
- 倒计时开始：划掉搜索误区，完成 72 小时行动链
- 找到入口：选择正规入口并了解专业评估过程
- 第28天：规范完成 PEP 并按建议检测复查
- 下一次可以更早：按暴露前、暴露后和确认状态制定预防方案
- 发出去之前：保护求助者隐私，亲手制作 72 小时行动指南并回应污名化观点

Q 的真实身份、性别和关系始终不会公开。游戏不替代专业医疗建议，不替医生判断是否需要 PEP，也不提供个体用药方案。

## 本地预览

直接打开 `index.html`，或在项目目录启动一个静态网页服务。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个空仓库，不要勾选初始化 README。
2. 上传 `index.html`、`styles.css`、`app.js` 和 `.nojekyll`。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 `main` 分支和 `/ (root)` 文件夹并保存。
6. 等待 GitHub Pages 完成部署，页面地址通常是：
   `https://你的用户名.github.io/仓库名/`

这是一个纯静态网页，不需要服务器或数据库。

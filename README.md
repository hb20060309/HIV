# 我们先说清楚

面向大学生与青年群体的第一人称 HIV 健康互动叙事游戏。

玩家从自己的生活视角出发，经历潜在暴露后的信息整理、传播途径辨别、检测预约、朋友陪伴、预防计划和公共讨论。游戏不展示任何角色的检测结果，不把身份、性取向或关系状态与感染风险绑定，也不使用“答错即失败”的考试模式。

## 主要内容

- 序章：创建你的视角
- 第一章：那一晚之后
- 第二章：到底什么会传播
- 第三章：要不要检测
- 第四章：他只说，想去检测
- 第五章：下一次可以更早
- 第六章：你会怎么说
- 五种基于行动、信任与隐私后果的结局

## 运行方式

这是一个不依赖服务器和构建工具的静态网页。直接打开 `index.html` 即可运行。

仓库的 GitHub Actions 会在 `main` 分支更新后自动发布到 GitHub Pages。

## 内容边界

游戏中的健康信息用于科普，不能替代个体化医疗建议。具体检测、用药和随访安排应咨询当地正规医疗卫生机构。

# 我们先说清楚

面向大学生和青年群体的简笔画互动叙事游戏原型。

## 本地预览

直接打开 `index.html`，或在项目目录启动一个静态网页服务。

## 发布到 GitHub Pages

1. 在 GitHub 创建一个空仓库，不要勾选初始化 README。
2. 上传 `index.html`、`styles.css`、`app.js` 和 `.nojekyll`。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 `main` 分支和 `/ (root)` 文件夹并保存。
6. 等待 GitHub Pages 完成部署，页面地址通常是：
   `https://你的用户名.github.io/仓库名/`

这是一个纯静态网页，不需要服务器或数据库。
